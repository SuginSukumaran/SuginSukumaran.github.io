### Secure OT File Transfer Architecture

Replaced direct legacy file sharing with encrypted OPC UA communication, X.509 certificate-based mutual authentication, integrity validation, network segmentation, and controlled staging between IT and OT zones.

**Keywords:** OPC UA, AES-256, SHA-256, X.509, Basic256Sha256, Suricata IDS, Wireshark, VLAN segmentation, IEC 62443 principles.

### Residential PV-Battery and Grid-Interaction Simulation

Developed a MATLAB/Simulink model of a four-household residential PV-battery system using the CARNOT Toolbox. Analysed solar irradiance, load profiles, battery state of charge, grid import/export, time-of-use tariff behaviour, and battery-parameter tuning across a seven-day simulation.

**Outcome:** A tested larger-battery configuration achieved zero grid import for the evaluated household case.

**Keywords:** MATLAB, Simulink, CARNOT Toolbox, Open-Meteo API, battery SoC, distributed energy resources, tariff analysis.

[View project in portfolio](https://suginsukumaran.github.io/#projects)

### PINN Vehicle State Estimation

Developed a Physics-Informed Neural Network framework for estimating vehicle lateral velocity and side-slip angle from vehicle-dynamics data. Evaluated physics-loss scheduling, sampling approaches, cross-vehicle generalisation, and hybrid PINN + RNN/TCN correction architectures.

**Outcome:** The best PINN + TCN configuration reduced self-loop lateral-velocity RMSE from 0.462 m/s to 0.369 m/s—a 20.1% improvement over the standalone self-loop PINN.

**Keywords:** Python, PyTorch, PINNs, TCN, LSTM/GRU, Ray Tune, HyperOpt, Optuna, vehicle dynamics.

[View project in portfolio](https://suginsukumaran.github.io/#projects)

### Bayesian Black-Box Optimisation

Built a surrogate-based optimisation workflow for a noisy 15-parameter black-box yield-function challenge with strict evaluation-budget limits. Used historical experiment data, Gaussian Process Regression/Kriging, uncertainty estimates, Upper Confidence Bound, and Expected Improvement strategies to guide candidate selection.

**Result:** Second Place — TH Köln Black-Box Optimization Challenge, Summer Semester 2025.

**Keywords:** Python, Gaussian Process Regression, Kriging, Bayesian optimisation, UCB, Expected Improvement, scikit-learn.

[View project in portfolio](https://suginsukumaran.github.io/#projects)
