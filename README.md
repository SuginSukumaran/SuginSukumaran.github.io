## Featured Engineering Projects

### Secure OT File Transfer Architecture

Designed a defense-in-depth architecture for secure file delivery to legacy OT systems using encrypted OPC UA communication, X.509 certificate-based mutual authentication, AES-256 encryption, integrity validation, network segmentation, controlled staging, and IEC 62443 principles.

**Keywords:** OPC UA, X.509, AES-256, SHA-256, Suricata IDS, Wireshark, VLANs, OT cybersecurity.

### SINUMERIK ONE Virtual CNC Commissioning

Commissioned and validated a virtual three-axis CNC system using SINUMERIK ONE, Siemens TIA Portal V20, Create MyVirtualMachine, PLCSIM Advanced, SINAMICS S120, and simulated PROFINET I/O.

**Validation:** Axis JOG motion, feedrate override, PLC–NC–HMI communication, emergency stop, alarm/reset behaviour, and virtual-NCU download troubleshooting.

### PINN Vehicle State Estimation

Developed a Physics-Informed Neural Network workflow for lateral-velocity and side-slip-angle estimation using cross-vehicle racing data. A hybrid PINN + Temporal Convolutional Network reduced self-loop lateral-velocity RMSE from **0.462 m/s to 0.369 m/s**, a **20.1% improvement**.

**Keywords:** Python, PyTorch, PINNs, TCN, LSTM/GRU, Ray Tune, HyperOpt, Optuna, vehicle dynamics.

### Bayesian Black-Box Optimisation

Built a Gaussian Process/Kriging surrogate-model workflow for a noisy 15-parameter black-box optimisation challenge with limited experiment budget. Used historical experiment data, UCB and Expected Improvement acquisition strategies to guide candidate selection.

**Result:** Second Place — TH Köln Black-Box Optimization Challenge, Summer Semester 2025.

**Keywords:** Gaussian Process Regression, Kriging, Bayesian optimisation, UCB, Expected Improvement, Python, scikit-learn.

### PCA and Industrial Data Analytics

Created a Python-based workflow for feature exploration, correlation analysis, dimensionality reduction using PCA, regression benchmarking, and interpretation of energy-related datasets.

**Keywords:** Python, pandas, NumPy, scikit-learn, PCA, matplotlib, seaborn, statsmodels.
